# Keyboard shortcut setup

Configure these in **Settings → Keyboard → Keyboard Shortcuts** (names vary by desktop).

| Action | Suggested shortcut | What to configure |
|---|---|---|
| Open terminal | `Ctrl + Alt + T` | Launch terminal |
| Open app launcher | `Super` | Applications overview/search |
| Switch windows | `Alt + Tab` | Next window |
| Switch workspace | `Ctrl + Alt + Left/Right` | Previous/next workspace |
| Screenshot | `PrtSc` | Screenshot tool |
| Lock screen | `Super + L` | Lock screen |

## Visual consistency checklist
- [ ] Terminal profile uses a dark background and high-contrast text.
- [ ] Prompt uses cyan for username/host, purple for directory, green for command marker.
- [ ] Launcher and top/status bar use a matching dark theme/accent where supported.
- [ ] Window decoration theme matches the overall desktop.
- [ ] Take a screenshot of the actual desktop and shortcut settings for the submission.

Shortcut names differ by desktop. Do not claim a shortcut is configured until you have set and tested it.
