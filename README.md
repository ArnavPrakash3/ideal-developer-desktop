# Required genuine screenshots

Save screenshots of your real configured environment in this folder:
- `terminal-theme.png` — terminal showing the themed prompt.
- `system-status.png` — system-status script running.
- `keyboard-shortcuts.png` — desktop keyboard shortcut settings.
- `desktop-overview.png` — desktop/launcher/window theme.

Capture them with your computer's screenshot tool. Do not use mockups or screenshots from someone else's machine.
